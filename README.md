## 📌 Overview
This project analyzes bikeshare data from major U.S. cities, providing insights into travel patterns, peak usage times, and user demographics.

## 📊 Features
- Load and filter trip data by city, month, and day
- Calculate trip duration, peak travel times, and popular stations
- Display user statistics, including user types and gender distribution (if available)

## 🏙️ Cities Covered
- Chicago
- New York City
- Washington

## 🖥️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Jawonc/bikeshare-project.git
   ```
2. Navigate to the project folder:
   ```bash
   cd bikeshare-project
   ```
3. Run the script:
   ```bash
   python bikeshare.py
   ```

## ⚙️ Requirements
Install the required dependencies using:
   ```bash
   pip install pandas, colorama, tabulate
   ```
